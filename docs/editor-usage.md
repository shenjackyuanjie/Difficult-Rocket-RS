# 编辑器操作指南

[返回 README](../README.md) · [验证方法](validation.md) · [当前状态](editor-progress.md)

## 底部图标栏与抽屉

编辑器使用一条 **56px 高的底部图标栏**，画布上方不再常驻旧顶栏。左侧保留三个原生 UI 入口：

| 入口 | 用途 |
| --- | --- |
| Menu | 文件菜单：新建、打开、保存、另存为等 |
| Staging | 打开属性/分级；与 F2 相同，未选部件时定位驾驶舱 |
| Help | 操作帮助；与 F1 相同 |

其余空间是同一行的 44×44 图标按钮：Parts（部件）、撤销、重做、适配视野、Ships（船体）、Tools / More（更多工具），待放置时另有取消入口。三枚原生入口与这些图标按钮同高、同 48px 间距排成一条连续工具栏，顶部强调线贯通整条底栏，不再读作两组。悬停可查看提示，窄窗会减少快捷图标，可从 Tools 访问目录切换和其他编辑设置。

**Parts、Ships、Tools 默认全部关闭，并且彼此互斥**：点击一个入口打开对应抽屉，同时收起另一个；再次点击同一入口或抽屉关闭按钮即可回到画布。Parts 展示右侧部件目录，Ships 展示左侧船体目录，Tools 集中子节点跟随、吸附、自由模式、连接树/图和连接线等设置。打开属性/分级**不再收起目录抽屉**：停靠分级占用左侧，可同时打开右侧 Parts / Tools 或左侧 Ships，画布是三者之外剩下的真实区域。

## 手动操作

| 操作 | 按键 |
| --- | --- |
| 选择、移动并吸附部件 | 左键点击、拖动 |
| 增减选择、框选、全选 | Shift+左键；默认中键拖动框选，Tools 可切换为左键；Shift 框选追加；Ctrl+A |
| 复制、剪切、粘贴 | Ctrl+C/X/V；预览中 R/X/Y 变换、左键/P 提交、Esc/右键取消 |
| 从目录拖出新部件 | 打开 Parts 后，从列表任一行左键按住拖到画布，松手放置并吸附连接 |
| 拖拽中旋转、镜像、重叠落下 | 按住左键时按 R、Q/E、Shift+Q/E 或 X/Y；姿态与位移一次撤销，Esc/右键取消；拖拽中不复制 |
| 取消拖动预览 | Esc、右键；窗口失焦时自动取消；旋转与位移预览一并撤销 |
| 切换待放置部件、放置 | 按分组顺序在未收起的类别中 Tab / Shift+Tab 切换；左键点击画布或 P 放置 |
| 删除、旋转、镜像 | Delete；R 为 90°，Q/E 为 ±15°，Shift+Q/E 为 ±1°；X / Y 镜像 |
| 撤销、重做 | Ctrl+Z、Ctrl+Y |
| 连接树 / 连接图编辑 | F6 或 Tools 中的“连接树 / 连接图”；Esc 关闭 |
| 属性与分级编辑 | F2 或底部 Staging；未选部件时打开驾驶舱 |
| 新建、打开 | Ctrl+N、Ctrl+O；支持单个 XML 文件拖入 |
| 保存、另存为 | Ctrl+S、Ctrl+Shift+S；首次保存选择目标文件 |
| 鼠标位置缩放、平移、视图复位 | 滚轮；默认左键拖动空白平移（左键框选模式下改用中键）；Home |
| 适配整船、适配选区 | F、Shift+F；视图居中到当前可用画布 |
| 调试显示、船体显隐 | F3 显示坐标、原点和选中轮廓/连接面；F4 隐藏或恢复贴图 |
| 子节点跟随 | Tools 中的跟随图标开关，**默认开启**；开启后拖父节点带所有子孙并保留内部连接，不带上级父节点；关闭则只拖当前选区 |
| 吸附 | Tools 中的吸附图标开关，默认开启；关闭后放置与拖动按指针位置落点、不再对齐连接点也不再自动建连，已有连接保留。吸附与自由模式是两个独立开关，互不联动 |
| 自由连接 | Tools 中的自由模式图标开关；依次点击两个部件的连接点或连接边建立连接，重复选择同一对端点可断开；Esc/右键取消选点。它控制几何与断连策略，与吸附开关独立 |
| 拖入列表删除 | 打开 Parts 后，拖现有部件到右侧部件列表松手，删除整个相连分量；Ctrl+Z 一次撤销 |
| 操作帮助 | F1 或底部 Help；窗口默认居中、可用标题栏拖动，F1 / Esc 关闭；底部图例用真实颜色显示候选 / 吸附 / 未连接 |
| 截图 | F12，输出到当前目录 |

视图适配包含旋转后的贴图与真实实体轮廓，并使用侧栏和工具栏实际留下的画布区域；窗口最小尺寸为 320×320，调整窗口后可按 F 或“适配视野”重新适配。调试和显隐只影响显示，不改文档或撤销历史；属性草稿中不触发这些快捷键。


## 目录与放置

从底栏打开 Ships 后，左侧船体列表只列可解析的 XML，支持切换目录、刷新和虚拟滚动。打开 Parts 后，右侧部件按原版顺序分为通用组件（Gizmos）、燃料罐（Fuel Tanks）、发动机（Engines）、卫星部件（Satellite），各组独立展开/收起，“全部展开”恢复。原目录可见成员为 8 / 4 / 6 / 7；隐藏项不显示。显式 XML `category` 优先，自定义组原名保留并追加，视图推断不写回 XML。

目录点击和 Tab / Shift+Tab 跳过同一批收起组。部件使用连续 64px 行、固定图片列及等比缩略图，长名截断。单击进入连续放置预览；从任一行拖到画布则抬起后放置。合法吸附为绿色，碰撞/超数量为红色，提交与连接合并为一次撤销；拖回侧栏、Esc/右键、失焦或文件操作取消目录拖放。

打开 Parts 后，现有部件拖入右侧目录并松手会删除整个相连分量，不受后代跟随开关影响；其他侧栏释放只取消。引用有歧义时拒绝删除，不猜归属。

## 选区与连接

Shift 多选、框选、子树/连通选择共用选区。整体旋转/镜像同步改变位置与姿态，保留内部连接；抓住父节点时，“子节点跟随”递归包含后代、不带上级，范围在开始拖拽时固定。松手将位移与变换合为一次历史；取消不改文档。

辅助模式的吸附距离为 0.35 Ship 单位，实体相交面积必须严格小于较小实体的 5%（恰好 5% 拒绝）。Shape 并集、轮子圆形及镜像/任意角度参与计算，sensor 不作为实体。新放置/粘贴与非拖拽变换拒绝超限重叠；现有部件拖动可保留超限落点，但不新建连接，断开外部连接并保留选区内部连接。固定点/共享 group 检查占用，连接边允许沿边滑动；对接类型仍须兼容。

自由模式关闭自动吸附、几何碰撞和自动断连；依次点两个端点可连接，再点同一对可断开。不同、可唯一引用的部件与合法连接点仍是要求；每对部件只允许一条边，反向或换点不能新增重复边。模式与显示设置不写 XML、不新增历史，切回辅助模式不主动改写自由连接。

F6 打开连接树/图：树为保留额外边的生成森林，换父拒绝自连接、后代环和多父歧义；图可显示并编辑合法环。普通/对接边可精确断开一次撤销，悬空或歧义引用单列。拖动图节点仅改变图布局，不移动船体。窗口打开时取消画布预览并隔离编辑快捷键。

“连接线设置…”提供显示、颜色/透明度、1–12px 粗细、线型、呼吸/流动与父→子箭头，Esc 关闭；隐藏线不隐藏自由模式端点。设置仅对本次会话显示生效。未连到主驾驶舱的部件淡化，历史歧义连接不猜端点。

## 属性、文件与数据安全

F2 或 Staging 打开选中部件或驾驶舱属性：激活、燃料、名称、油门及分级动作统一在草稿中编辑。Apply（应用）原子提交一次撤销，Cancel（取消）放弃整个草稿；没有拖放手势进行时，Esc 也可取消草稿。普通部件属性、重复编号修复仍使用 Modal，点击遮罩不会丢草稿；驾驶舱属性/分级使用下述停靠界面。校验燃料容量、油门 0～1、分级目标存在且本级不重复。**停靠的驾驶舱分级草稿不再锁住画布**：仍可选择、拖动、框选、放置部件并使用编辑快捷键；Ctrl+Z / Ctrl+Y 先撤销或重做草稿内的编辑，草稿历史耗尽后才回落到文档历史，底栏与工具抽屉的撤销/重做按钮同此语义。文件相关操作仍要求先应用/取消；IME 事件同帧的 Esc 不关闭草稿。再次按 Staging / F2 时：草稿未修改则收起，有修改则保留草稿并给出提示。

### 分级与船体对照

- 横向空间足够时使用左侧紧凑停靠，窄窗停靠底部；打开时**不再收起目录抽屉**，可与右侧部件 / 工具抽屉共存。打开或改变尺寸时自动显示、适配整船；草稿期间画布仍可拖动、框选、放置并处理 Ctrl+Z / Ctrl+Y。
- 面板上方保留 Generate（生成基础分级）、添加步骤、Targets（目标）、Advanced（高级）、Apply、Cancel 等常用入口。Targets 与 Advanced 默认收起，需要时再展开；应用/取消始终位于滚动正文之外。
- 每步是一张卡片，标题显示序号与动作数；动作使用可换行的缩略图小块。点击动作后显示它的“移动”标记与移除入口；“移除”只删除分级动作，不删除部件。卡片从 `01` 起显示，执行索引和 XML 仍从 0 起。
- 悬停卡片标题或动作，船上对应部件显示半透明青柠高亮、轮廓与 `#ID`；移开后恢复已选目标。点击动作、修改“移动”或选择目标则保留联动。只标本组可唯一解析的部件，不猜重号或缺失引用，不改变文档选区与历史。

### 基础分级：显式生成

打开 Staging/F2、读入 XML 或摆好部件都不会自动生成分级。请在驾驶舱分级面板中主动点击 **Generate**：成功后替换当前草稿中的分级计划，并把执行索引设为 0；原文档和撤销历史此时保持不变。检查后点击 Apply，整个草稿合为一次历史提交，可撤销/重做；Cancel 放弃生成结果。已有手动计划也会被生成结果替换，因此需要保留时先取消或保存原计划，而不是把 Generate 当作合并按钮。生成失败时保留原草稿并显示原因。

生成规则以选定 Command Pod 为根，只处理**同组、经 Normal 连接可达的完整无向树**：每经过一条连接边深度加 1，燃料罐等无激活动作的部件同样参与深度计算。仅收集 Engine、Detacher、Parachute；按深度从深到浅排列，同深度按 Engine → Detacher → Parachute 排列，同深度且同类的目标归到同一卡，卡内按部件 ID 升序。新动作的 `moved` 全为 false，不生成空卡；没有这三类动作时得到空计划。

其他组或不连通部件不参与本次生成。可达部分若有 Dock、环、重复边、悬空/重号歧义、未知类型或另一驾驶舱等，生成会给出错误而不是猜测。此功能提供可检查的基础顺序，不计算燃料耗尽、推力或飞行策略，也不宣称完全复刻原版分级遍历；复杂连接和特殊任务仍需手工安排。

### 手动拖放调级

在卡片标题或动作小块上**按住左键，移动越过拖动阈值，再在目标处松开**；移动中显示插入位置，释放时才改变草稿。单击仅用于选择，不等同于拖动。

- **整卡重排**：从卡片标题拖起，落到目标标题上半部插到它前面，下半部插到它后面；卡内动作及已有 `moved` 值一并保留。
- **动作调级**：从动作小块拖起，放到目标卡标题上会追加到卡尾，空卡也可接收；放到某个动作小块左半部插到该动作前，右半部插到其后。同卡重排保留原 `moved` 值；跨卡移动只把被移动动作设为 `moved=true`，源卡变空时仍保留。
- `moved` 是 XML 中的动作标记，拖放不会挪动船体几何。目标卡已有同 ID 动作时拒绝整次移动，既不从源卡删除，也不复制动作。
- 无效落点、失焦或指针离开窗口会取消当前拖动；拖动中按 Esc 只取消这次手势，保留此前草稿。结束手势后仍须 Apply 才写入文档；Cancel 或非拖动时的 Esc 放弃整个草稿。

### 连续三级火箭示例

从新文档已有的 Command Pod（隐藏目录项 `pod-1`，ID 1）开始；不需要在 Parts 可见列表中另找驾驶舱。依次选件、在画布查看预览并吸附放置以下串联结构，部件 ID 随放置依次为 1～9：

`pod-1 → fueltank-0 → engine-0 → detacher-1 → fueltank-0 → engine-0 → detacher-1 → fueltank-0 → engine-0`

1. **搭建**：从单 Pod、0 连接、空分级到 9 部件、8 条 Normal 连接；其中有 3 台发动机、2 个分离器，组成三个物理推进段。放置预览不改文档，每次确认放置与新增吸附连接合为一次历史。
2. **自动基础分级**：点击 Generate 得到 `[[9],[7],[6],[4],[3]]`，每个内层列表表示一张卡的目标 ID，全部 `moved=false`。先检查草稿，再 Apply；可用撤销/重做确认文档变化。
3. **手动调级**：把发动机 6 拖到分离器 7 所在卡的标题处，得到 `[[9],[7,6],[],[4],[3]]`，仅 6 为 `moved=true`。可把整卡拖到另一位置再拖回；Cancel 后文档仍为已应用的自动计划，重新操作并 Apply 才保存手动计划。

演示中的三阶段共用同一文档。详细的三用例、九产物和 XML 对照要求见[连续三级火箭章合同](demo-review-suggestions.md#连续三级火箭章合同)；这是报告合同，完整 GUI 的实际通过状态以[当前状态](editor-progress.md)与[验收记录](validation-history.md)为准。

### 文件与引用安全

同 ID 按组与实例定位，不自动重编号。跨组吸附合并相关组，并重映射冲突 ID、连接及分级引用；新编号避开历史悬空引用。F2 中“修复引用归属”要求逐字段指定重号实例，应用一次撤销，取消不变；打开/保存不自动修复。

新建、打开和退出前，未保存模态提供保存后继续、放弃或取消；保存失败/选择路径取消保留文档，点击遮罩不放弃。原生路径选择绑定编辑器 owner，等待期间主窗口持续更新。XML 保存先写同目录临时文件再替换目标，不直接截断原文件；无法无损解释的字段或根结构明确拒绝。

历史默认最多 256 步、64 MiB 快照预算，至少保留最近一步；预算不含当前文档、保存点、渲染及分配器开销。复制保留内部连接/分级，文件切换保留剪贴板，但取消未提交预览。

## 触摸与小屏

鼠标、键盘、触摸共用同一界面。单指拖动、抬指放置/粘贴一次提交；双指导航会取消未提交编辑，全部抬指后才重新允许单指。UI 起点触摸整段归 UI，不因越界编辑画布。窄窗通过底栏 Parts、Ships、Tools 打开互斥抽屉；空间不足时可从 Tools 切换目录，选取后回到画布，入口至少 44px。

详细仲裁、设备与平台边界见[触控说明](mobile-support.md)。可用画布随底栏、抽屉与停靠面板变化，必要时按 F 或点击“适配视野”；窄窗布局适配不等于物理触屏验收。

## Windows 便携包

```powershell
cargo build --workspace --release --locked
uv run --no-project --python 3.12 python -B -X utf8 scripts/package_editor.py --output target/dist/dr-editor-win64.zip
```

现有打包脚本收集相邻资源、中文字体及 Solar、R、Co13、Gzj、Test、Heronb 六个范例，附源码快照、许可及逐文件/ZIP SHA-256。解压后双击 `Start.cmd`，无需 Rust/Python；支持中文与空格路径，参数继续传给编辑器。输出已存在时拒绝覆盖，请换新名称。

目标为 Windows 10/11 x64，需 Vulkan 或 DirectX 12 驱动；缺少 `VCRUNTIME140.dll` 时可安装 [Microsoft Visual C++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。此脚本不是移动端打包工程；是否已生成并启动当前构建的包，以本次验收记录为准。
